# rachwest-flightdeck

A clean aviation-themed portfolio site built with Next.js and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Build

```bash
npm run build
```

## Notes

- This repository contains the minimal source for the portfolio landing page.
- The site is designed for static deployment.
- Main content lives in `src/app/page.tsx` and global styles are in `src/app/globals.css`.
